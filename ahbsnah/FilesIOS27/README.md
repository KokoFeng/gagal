# Files iOS 27 (Android)

Cara pakai di HP (AndroidIDE):
1. Ekstrak zip ke /sdcard/Download/FilesIOS27
2. Buka folder itu di AndroidIDE, lalu Build > Build APK (debug)
3. Install APK, buka, tekan "Allow Access" dan aktifkan "Allow access to manage all files"

Fitur: Recents / Shared / Browse, grid & list, pencarian + mic, popup tahan-lama ala iOS,
Rename, Compress (zip), Extract, Install APK, Duplicate, New Folder with Item, Tags warna,
Copy/Move + Paste, Share, Get Info, Delete. Viewer foto (pinch, double-tap), video, audio, teks (bisa edit & Save).
Kursor biru iOS bergerak halus (IosEditText). Swipe dari tepi kiri untuk kembali.
